# Audios de la presentación ACUA

Coloca aquí los audios con el nombre `slide-<número>.<ext>`, por ejemplo `slide-1.mp3` para el slide 1.

- **Formatos:** `.mp3`, `.m4a`, `.ogg` y `.wav` (recomendado: MP3 a 128 kbps para que cargue rápido en móviles).
- **Vinculación:** cada audio se asocia automáticamente a las imágenes del mismo número de slide, en `public/media/acua/images/` (`slide-1.jpg` o `slide-1-1.jpg`, `slide-1-2.png`...).
- **Sin audio:** el slide usa la voz sintética para leer su texto.

Consulta todas las reglas en el `README.md` principal del proyecto.
