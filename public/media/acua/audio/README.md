# Instrucciones para subir Audio e Imágenes (Presentación ACUA)

Aquí puedes colocar los archivos de audio e imágenes para la presentación **ACUA**.

### Formatos soportados:
- **Audios**: `.mp3`, `.m4a`, `.ogg`, `.wav` (recomendado: MP3 128kbps para carga rápida en móviles).
- **Imágenes**: `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.

### Nombres por defecto para ACUA:
Coloca tus audios en esta carpeta (`public/media/acua/audio/`):
- `slide-1.mp3` -> Audio para la Sala 1 (Introducción)
- `slide-2.mp3` -> Audio para la Sala 2 (Profundidades Abisales)
- `slide-3.mp3` -> Audio para la Sala 3 (Arrecifes de Coral)
- `slide-4.mp3` -> Audio para la Sala 4 (Corrientes Oceánicas)
- `slide-5.mp3` -> Audio para la Sala 5 (Conservación del Océano)

Coloca tus imágenes en `public/media/acua/images/`:
- `slide-1.jpg` (o `.png` / `.webp`)
- `slide-2.jpg`
- `slide-3.jpg`
- `slide-4.jpg`
- `slide-5.jpg`

> **Nota:** Puedes editar las rutas o nombres de archivo en `src/data/presentations.js` si prefieres otros nombres. Si el archivo de audio aún no se ha subido, la aplicación incluye automáticamente un sintetizador de voz (Web Audio / Speech) de prueba para que los botones de reproducir, pausar y avanzar funcionen sin errores mientras subes tus audios definitivos.
